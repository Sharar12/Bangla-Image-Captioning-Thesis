# Changelog

## [2.0.0] - 2026-06-29
### Added
- Self-Critical Sequence Training (SCST) policy gradient optimization with CIDEr reward.
- Diverse Beam Search with Hamming diversity penalties.
- Dynamic INT8 quantization for edge and CPU inference deployment.
- FastAPI REST microservice endpoints.
- Error taxonomy analysis suite (CHAIR hallucination evaluation).
- v2.0.0 interactive Gradio application with side-by-side model comparisons.

## [1.0.0] - 2025-10-28
### Added
- Core dataset preprocessing and Bengali text normalizer.
- ResNet-50, ViT, and SigLIP2 vision encoder backbones.
- Additive Bahdanau attention and GRU/LSTM decoders.
- Benchmark evaluation suite for BLEU, ROUGE-L, METEOR, and CIDEr.
