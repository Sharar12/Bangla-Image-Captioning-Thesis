# BanglaVision API Reference

## Encoders
- `SigLIP2VisionEncoder`: Extracts spatial patch embeddings from 224x224 RGB inputs.
- `ResNet50Encoder`: Convolutional feature extractor baseline.

## Decoders
- `AttentionDecoderGRU`: Bahdanau attention recurrent language generator.
- `DiverseBeamSearchDecoder`: Multi-group diversity-enforced beam search.
