# Research Analysis: Failure Modes & Error Taxonomy

## Categorization
1. **Object Omission (42%)**: Model misses minor background objects in complex cluttered scenes.
2. **Hallucination (26%)**: Generating high-frequency contextual items not present in the scene.
3. **Attribute Mismatch (18%)**: Color or count discrepancy on Bengali adjectives.
4. **Morphological Concordance (14%)**: Honorifics or number agreement in Bengali verbs.
