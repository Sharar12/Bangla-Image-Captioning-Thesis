# Model Card: BanglaVision

## Model Details
- **Architecture**: SigLIP2 Vision Encoder + BanglaGPT Projection Adapter with Bahdanau GRU Decoder.
- **Training Objective**: Cross-Entropy with Label Smoothing followed by SCST CIDEr optimization.
- **License**: MIT
- **Primary Intended Use**: Automatic generation of descriptive Bengali captions for natural scenes.
